# Project Overview

Anime Character Director combines a Codex Skill, a local deterministic Python runtime, and the built-in image generation tool into a gated character-design workflow.

The current model is standee-first, human-in-the-loop, and evidence-scoped. It is not an independent autonomous agent, external API service, or server product. Existing runtime files, reports, tests, and untracked artifacts were preserved during Wiki initialization.
